# 福建省作品自愿登记系统 · 强制电脑版 + 自动登录助手

作者：Heyden Lin
首次发布：2026-08-07
许可证：MIT

## 这是什么
一个 Tampermonkey 用户脚本，改善「福建省作品自愿登记系统」(copyright.fjxuanchuan.cn) 的桌面使用体验。

## 功能
- 强制电脑版：不再被强推手机 H5 页面
- 自动处理"登录状态已过期"弹窗（自动点确定，默认跳登录页；加 ?nojump 可原地重登）
- 心跳保活：延长闲置时长

## 使用方法
1. 浏览器安装 Tampermonkey 插件
2. 安装本脚本（fj-copyright-auto-home.user.js）
3. 打开登记系统即可使用，默认生效

## 说明
- 本脚本为个人工具，不修改官方系统，治标不治本。
- 登录会话约几小时的上限由服务端决定，脚本无法去除，仅将"弹窗→重登"自动化。
